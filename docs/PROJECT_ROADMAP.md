# UAV Beam Prediction Project Roadmap

## Project objective

Evaluate sensing-aided beam prediction on DeepSense 6G Scenario 23, distinguishing prediction of the beam at the current observation from prediction of a future beam. Report predictive accuracy and practical beam-scan/power trade-offs. Keep model selection on validation data and use sequence-grouped evaluation for generalization.

## Current-beam benchmark protocol

- Input: one synchronized RGB image and/or the 11 sensor features at time t; the fine-tuned model uses the RGB image directly.
- Target: the recorded beam index at that same time t.
- Baselines/models: previous-beam persistence where available, visual-only, sensor-only, and learned gated fusion.
- Data split: use the existing sequence-grouped train/validation/test assignment; confirm that no sequence appears in multiple splits.
- Checkpoint selection: validation Top-1 only. Evaluate the test split after each model is fixed; do not tune on test results.
- Metrics: Top-1/3/5, macro-F1, per-class support, and measured-power regret for the selected beam and Top-K shortlist.
- This is a controlled current-beam benchmark inspired by the references, not an exact replication of their architectures or their 70/30 sample split. The sequence-grouped evaluation is intentionally kept as our generalization protocol.
